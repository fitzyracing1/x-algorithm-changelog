# New zero-weighted heads (video continuation, profile visit time); popular posts precomputed

- **New ranking weights, all at `0.0` for now:** `VideoContinuationWeight`, `UserVideoContinuationWeight` and `ProfileVisitSecsWeight`, defined in `vm-ranker/params.rs`. The shared `xai-value-model` crate gets matching heads (its weight list grows from 25 to 28 entries). Home-mixer's own `value_model.rs` hard-codes the two video-continuation weights to `0.0`, so for now these heads don't change scores.
- New flag `PostUnexploredIncludeOutOfNetwork` (`vm-ranker/params.rs`, default off). Without it, the value model's post-unexplored bonus applies only to in-network candidates.
- `PopularPostsSource` now reads from a precomputed `PopularPostsCache` (new `util/popular_posts.rs`, filled by new `popular_posts_job.rs` / `popular_authors_job.rs`) instead of querying Thunder on each request. `PopularPostsTopAuthors`, `PopularPostsMaxPerAuthor` and `PopularPostsMaxRepliesRepostsPerAuthor` leave `param.rs`.
- New flags `EnableUnderTheHood` and `EnableHomeExcursionScores` (both off).
- `RetrievalCandidatesKafkaMaxCandidates` `200` → `100000`. `VMRankerClusterId` `"Experiment6"` → `"Experiment1"`.
