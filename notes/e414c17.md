# May 15 release: ads blending, Grox, more sources, hydrators and filters

A large update (187 files, +18,263/−926). The upstream README gained an "Updates — May 15th, 2026" section for this release, which is no longer in the current README.

- **New candidate sources** in `home-mixer/sources/`: `ads_source`, `cached_posts_source`, `phoenix_moe_source`, `phoenix_topics_source`, `prompts_source`, `push_to_home_source`, `scored_posts_source`, `tweet_mixer_source` and `who_to_follow_source`.
- **New scorers:** `ranking_scorer` and `vm_ranker` (the original `weighted_scorer`, `oon_scorer` and `author_diversity_scorer` files are still present).
- **New filters:** `ancillary_vf_filter`, `new_user_topic_ids_filter`, `previously_seen_posts_backup_filter`, `topic_ids_filter` and `video_filter`.
- **New selector:** `blender_selector`, plus a new `home-mixer/ads/` module for placing ads in the feed.
- Adds the `grox/` content-understanding service (classifiers, embedders, task engine) and many new query/candidate hydrators.
- Phoenix gets a single `run_pipeline.py` entry point and a pre-trained mini model distributed through Git LFS (`phoenix/artifacts/oss-phoenix-artifacts.zip`, about 3.1 GB).
