# "Dwell regret" scoring gate removed; Under the Hood shows legal withholding

- **Removed scorer `value_model_gate`** (537 lines). It was a per-viewer linear gate: it scored features from the viewer's recent action sequence and compared the score to a threshold to decide whether `ranking_scorer` should use the alternative "dwell regret" scoring path. Inside the hysteresis band, a hash of the user ID made the call. With it go 18 params: every `DwellRegret*` alpha/negative/gate/temperature param and `ValueModelMode`. `ranking_scorer.rs` loses 465 lines and gains 12.
- New param `PhoenixColdStartMaxResults` (default `0`, i.e. off). `PhoenixRetrievalMOEInferenceClusterId` changes from `"Experiment2Memy04"` to `"Experiment3Memy04"`.
- **Under the Hood:** the README's "September 18th, 2026" note says reports now show whether an account's or post's visibility was limited for legal compliance (e.g. withheld in a specific country). That matches the changes to `UthPctdAccountTakedownEventsJob.scala` and `underTheHoodLabels.strato`.
- Visibility filtering gets a new `tes_composite` hydration path and a batch `evaluate_tweets` API.
