# Ranking weights: click 0.4 → 0.3, click-dwell 0 → 0.4, not-interested −43.2 → −47.52

- **Weight changes**, made identically in `home-mixer/params/param.rs` and `vm-ranker/params.rs`: `ClickWeight` `0.4` → `0.3`. `ContClickDwellTimeWeight` `0.0` → `0.4`, so predicted time spent after clicking into a post now counts. `NotInterestedWeight` `-43.2` → `-47.52`, a 10% larger penalty.
- **Cold-start holdout:** in `author_cold_start.rs` the MoE "ranking policy" that zeroed arm-gated retrieval candidates for non-treatment viewers is removed, along with the `author_policy_zeroed` field. Holdout viewers no longer exclude arm-gated retrieval candidates from cold-start eligibility.
- New flag `PhoenixRetrievalExcludeSeenPosts` (default off). When on, Phoenix retrieval is sent the viewer's seen/served post IDs and impression bloom filters so it can skip posts already shown.
- The ads request now forwards the client's seen post IDs (`client_seen_post_ids`).
- Removed flag: `UseEngagementCounterViewCountForImpressionBoost`.
- README: documents `abuse-ledger-service/`. When an enforcement is overturned on appeal, it is not re-applied for a fixed period.
