# Ads blender switched to "multi_risk"

`AdsBlenderType` (feature switch `rust_home_mixer_ads_blender`) changes from `"partition_organic_low_risk"` to `"multi_risk"`. That makes the multi-risk blender added on Aug 28 the default for placing ads in the feed. Apart from home-mixer, this sync mostly touches `visibility-filtering/rules/`, `phoenix/` and `grox/`.
