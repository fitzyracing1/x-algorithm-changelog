Brazil 2026 election filter; Thompson-sampling params for author cold start

constantsfiltersnumeric tweaksparams
  • New filter Brazil2026ElectionFilter (home-mixer/filters/brazil_2026_election_filter.rs). It removes a candidate when its author, the retweeted author, the quoted author, or any author in the reply's ancestor chain is on a hard-coded list of accounts reported to Brazil's Electoral Court, unless the viewer follows that account. The list starts with 665 user IDs, and code comments cite the TSE open-data candidate dataset. The upstream README's "August 14th, 2026" notes describe the same filter.
  • Author cold start: new params EnableColdStartThompsonSampling (default off), ColdStartBetaAlpha0 = 0.75, ColdStartBetaBeta0 = 49.25, ColdStartTsTopK = 5, ColdStartImpressionScale = 1.0 and ColdStartTrackedIds. These let the cold-start boost choose among eligible low-impression posts by sampling a Beta posterior of likes per impression, rather than taking the highest-scored one.
  • Comments added to home-mixer/params/param.rs explain that each weight multiplies the *predicted* probability of an action, not raw engagement counts. The README is restructured into a "Latest Updates" list with an August 14th entry.
